# Windows Codex Toolkit

面向 Windows PowerShell 本地操作与 Kubernetes 只读诊断的可靠性 Skill Pack。

此目录是 Agensi MCP 分发源，不是独立安装目录。Agensi 按需加载对应的
`SKILL.md`、参考资料和脚本；原生 Codex 版本仍以仓库根目录下的 `skills/`
为兼容基线。

包内包含：

- `windows-local-ops`：Windows 本地 CLI、编码、路径和大文件读取。
- `windows-kubectl-reliable-ops`：kubectl、监控数据采集和瞬时故障处理。
